# 天光云影 Lite（sutvlite）

极致精简的 Android TV 直播播放器，只做一件事：**打开就是直播**。

专为老旧电视盒子（华为悦盒 EC6108V9 / 海思 Hi3798M / Android 4.4.2 / 1GB 内存）打磨。

## 特点

- **只有直播**：没有点播、没有收藏、没有历史、没有任何多余功能
- **只有咪咕源**：内置咪咕直播频道（分组 / 频道列表），无第三方采集源、无兜底源
- **打开即播**：启动直接开始播放上次观看的频道（首次为第一个）
- **极简交互**：上下左右换台，OK 唤出三段式选台面板（分组 | 竖线 | 频道）
- **换台只显示频道名**：一条蓝色横幅，无任何描述文字
- **三种方式进设置**：长按 OK / 连续 5 次菜单键 / 手机长按屏幕
- **设置只有两项**：分组和频道管理、特权功能（Root）
- **蓝色主调**：深蓝背景 + 蓝色高亮 + 白色文字

## 按键

| 按键 | 功能 |
|---|---|
| ↑ / ← | 上一台 |
| ↓ / → | 下一台 |
| OK（短按） | 选台面板 |
| OK（长按）/ 菜单键×5 / 长按屏幕 | 进入设置 |
| 返回 | 退出 |

选台面板内：上下在本栏选择，左右跨栏，OK 播放，10 秒无操作自动关闭。

## 设置

**分组和频道管理**：逐项切换 显示 / 隐藏，隐藏后不出现在选台面板

**特权功能**（需 root）
- Root 授权 / Root 诊断
- 安装为系统应用
- 锁定为桌面
- 进程守护
- 开机自启

## 技术要点（老盒子上踩过的坑）

- **TLS**：Android 4.4 的 OpenSSL 只报 TLS1.0，现代 CDN 直接拒绝。用 `ForceTls12SocketFactory` 包装套接字，强制上报并启用 TLS1.2
- **本地代理**：咪咕 m3u8/TS 经 `127.0.0.1:10481` 明文代理，彻底绕开盒子 TLS 与 CDN 的 UA/证书限制
- **时钟漂移**：盒子无 RTC 电池，时间戳会漂。用 HTTP `Date` 头 + playurl 响应里的 `timeStamp` 自动校准（否则报 `ERROR_TS_OVER_DUE`）
- **启动竞态**：开机后网络未就绪时，等网络 + 频道列表自动重试 + 网络恢复广播重试
- **API 19 兼容**：OkHttp 3.12、ExoPlayer 2.19、multidex；没有 Compose，纯 View + D-pad 焦点

## 构建

```bash
./gradlew :app:assembleRelease
```

产物：`app/build/outputs/apk/release/app-{armeabi-v7a,arm64-v8a,universal}-release.apk`

要求：JDK 17+、Android SDK（compileSdk 36）

## 说明

本项目仅用于个人设备上的电视直播播放，频道数据来自咪咕视频公开接口。
