# 极简直播（sutvlite）

面向 **老旧 Android 电视盒子** 的极简直播播放器。只做一件事：**打开就是直播**。

> 为华为悦盒 EC6108V9（海思 Hi3798M / Android 4.4.2 / 1GB 内存）打磨，实测可用。

---

## 当前状态：v1.0.0（正式版）

### 功能

| 模块 | 内容 |
|---|---|
| **直播** | 内置咪咕直播源（11 个分组 / 178 个频道），无第三方源、无兜底源 |
| **打开即播** | 启动后自动播放上次频道，失败自动重试，无需手动操作 |
| **换台** | ↑/← 上一台、↓/→ 下一台；中央圆环动画，出画面立刻消失 |
| **选台面板** | OK 唤出三段式面板（分组 ｜ 竖线 ｜ 频道），原生焦点导航，10 秒自动关闭 |
| **分组 / 频道屏蔽** | 逐项显示 / 隐藏，隐藏后不出现在选台面板，返回立即生效 |
| **设置入口** | 长按 OK / 连按 5 次菜单键 / 长按屏幕 |
| **设置界面** | 分组和频道管理、特权功能、关于（竖向卡片，灰黑白蓝配色）|
| **特权功能** | Root 授权与诊断、安装为系统应用、锁定为桌面 |
| **预约/异常处理** | 版权屏蔽频道 → 蓝屏提示 + 10 秒自动换台；连续 3 个无节目则停止跳台 |

### 已做的稳定性工作

- **应用自带时钟（AppClock）**：以 HTTP `Date` 为锚点 + 开机单调计时，签名时间不依赖盒子墙钟
- **开机等待界面**：不透明背景 + 圆环进度 + 倒计时，网络就绪自动进入播放
- **代理与直连自适应**：本地 `127.0.0.1:10481` 代理拉流，失败自动换路径 / 重新签发
- **DNS 多源 + 逐 IP 重试**：系统 DNS 失败时用公共 DNS 兜底，避免被污染解析拖死
- **强制 TLS1.2**：老盒子 OpenSSL 只报 TLS1.0，用 `ForceTls12SocketFactory` 强制协商
- **日志落盘**：`files/lite.log`（`adb logcat -s JJB` 也可看），便于排障

## 适配情况

| Android 版本 | 状态 | 说明 |
|---|---|---|
| **4.4 – 9** | ✅ **支持** | 主力目标。4.4.2（EC6108V9）已长期真机验证 |
| 10 – 12 | ⚠️ 未适配 | 网络判定用的 `activeNetworkInfo` / `/proc/net/route` 在新系统失效，会误报"获取不到 IP" |
| 13+ | ❌ 不支持 | 后台启动、通知权限等限制较多，不做适配 |

**硬件要求**：armeabi-v7a（或 arm64-v8a），建议 1GB 内存以上；网线接入（多数此类盒子无内置 WiFi）。

## 安装与使用

下载 `app-armeabi-v7a-release.apk`（悦盒等老盒子）或 `app-universal-release.apk`（通用），安装即可。

| 遥控按键 | 功能 |
|---|---|
| ↑ / ← | 上一台 |
| ↓ / → | 下一台 |
| OK（短按） | 选台面板 |
| OK（长按）/ 菜单键×5 / 长按屏幕 | 设置 |
| 返回 | 退出 |

## 已知问题

1. **开机后最初 40~90 秒可能无法播放**
   盒子断电后系统时间回到固件日期，运营商的网络出口也尚未稳定，此时咪咕 CDN 会拒绝请求。
   程序会自动等待并在就绪后开始播放（有圆环进度与倒计时提示），**无需退出重开**。
2. **每次换台可能先遇到一次 403，约 1~2 秒**
   运营商 CG NAT 出口 IP 与流地址里绑定的 `client_ip` 短暂不一致，程序会自动重新签发地址重试。
3. **部分频道显示"受运营商版权限制该频道暂无法播放"**
   该频道当前无节目或受版权限制，程序会在 10 秒后自动换台。

## 从源码构建

```bash
./gradlew :app:assembleRelease
```

产物：`app/build/outputs/apk/release/app-{armeabi-v7a,arm64-v8a,universal}-release.apk`

要求：JDK 17+、Android SDK（compileSdk 36）。minSdk 19 / targetSdk 19。
